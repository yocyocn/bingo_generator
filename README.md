# Bingo Generator

ブラウザだけで好きな項目のビンゴを作って、URLで共有できる静的サイトです。

| ページ | 役割 |
| --- | --- |
| `index.html` | ビンゴを作る（ビンゴ名・マスの数・FREEマス・項目・カラー）。プレビュー付き |
| `play.html` | URLからビンゴを表示して遊ぶ。マスをタップで ○、ビンゴ数の表示、コメント入力 |
| `result.html` | URLから結果（○の付いた盤面・ビンゴ数・コメント）を表示 |

## URLのパラメータ

| キー | 内容 |
| --- | --- |
| `t` | ビンゴ名 |
| `s` | サイズ（3 / 4 / 5） |
| `i` | 項目（改行区切り） |
| `c` | カラー（white / black / blue / yellow / pink） |
| `f` | FREEマスの表示内容（ないときはFREEマスなし） |
| `m` | 結果。左上から右下へマスごとに `1`（○あり）/`0` |
| `n` | コメント（100文字まで） |

## GitHub Pages で公開

リポジトリにこのフォルダの中身を push し、Settings → Pages で公開するブランチ（ルート）を選ぶだけです。ビルドは不要です。
